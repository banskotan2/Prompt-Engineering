# Senescence

This repository contains materials created as part of a class on prompt engineering and AI-assisted content generation.

## Disclosure

The contents of this repository were generated primarily using artificial intelligence (AI) tools in response to prompts created by the author. The project was completed as an educational exercise to explore prompt engineering, evaluate AI-generated outputs, and understand the capabilities and limitations of large language models.

AI-generated content may contain inaccuracies, omissions, or unsupported statements. While the outputs were reviewed and organized by the author, they should not be interpreted as expert advice or authoritative scientific or medical guidance.

## Purpose

The goals of this project are to:

* Demonstrate prompt engineering techniques.
* Explore AI-assisted content creation.
* Document the outputs generated during the course.
* Support discussion of the strengths and limitations of generative AI.

## Academic Use

This repository is intended solely for educational purposes as part of coursework. It is not intended to represent original research findings or peer-reviewed scientific work.
